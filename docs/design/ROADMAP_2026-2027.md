## 第一阶段：架构重构（P8-P9）— 地基

> **核心洞察 (Cavern Manticore 2026):** 国家级 C2 的核心不是植入体的逃避技巧，而是**模块化、版本化、多编译目标的框架架构**。Cavern 的三格式编译（IL-only / Mixed-Mode C++CLI / NativeAOT）使每个组件需要不同工具链才能逆向——这是反分析的架构层设计，不是代码混淆。

### P8. implant-core 抽象 — 跨平台共享层（6 周）

**目标:** 将协议、加密、beacon 调度、模块加载从 `implant-win` 提取到平台无关的 `implant-core` crate。

| 子任务 | 细节 | 交付物 |
|--------|------|--------|
| **P8a. Protocol core** | `Frame::seal/open`、`SessionKey`、`NonceManager` 提取为 `no_std` trait | `crates/implant-core/src/protocol.rs` |
| **P8b. Beacon scheduler** | `BeaconLoop` trait — `check_in() → poll_tasks() → execute() → sleep()` 跨平台抽象 | `crates/implant-core/src/scheduler.rs` |
| **P8c. Module loader** (Cavern 模式) | 编号版本化模块系统：`n-syscall-v3.dll` → `get_latest_dll("n-syscall")` 自动选最高版本。每模块独立内存空间，卸载不留痕 | `crates/implant-core/src/module.rs` |
| **P8d. Platform HAL** | `Platform` trait — `alloc_rwx()`, `syscall()`, `sleep()`, `resolve_api()`, `current_pid()` | `crates/implant-core/src/platform.rs` |
| **P8e. Crypto abstraction** | `CryptoProvider` trait — 经典 (X25519+ChaCha20) / 后量子 (ML-KEM+ChaCha20) 可插拔 | `crates/implant-core/src/crypto.rs` |
| **P8f. Task dispatch** | 统一 `Task` enum + `TaskHandler` trait — 平台无关的任务定义，平台相关的执行 | `crates/implant-core/src/task.rs` |

**验收:** `cargo test -p nyx-implant-core` 全绿。Windows/Linux/macOS 三个空壳 agent 均能 check-in + beacon loop。

### P9. 模块化架构 + 三编译目标（4 周）

> **Cavern Manticore 2026 标准:** 同一套代码编译为三种不同格式的二进制，每种需要不同工具链逆向。

| 子任务 | 细节 | 交付物 |
|--------|------|--------|
| **P9a. 编译目标矩阵** | `x86_64-pc-windows-gnu` (GNU as) · `x86_64-pc-windows-msvc` (MASM) · IL-only (通过 `dotnet` 互操作) — 三种格式，三种工具链 | `crates/implant-win/.cargo/config.toml` |
| **P9b. Module SDK** | 第三方模块开发规范：`Module` trait + `ModuleManifest` (版本号、兼容平台、签名哈希) | `crates/module-sdk/` |
| **P9c. 热更新** | `update_module(name, bytes)` — 接收 C2 下发的模块二进制 → 校验签名 → 替换当前模块 → 重新加载。Cavern 的 `get_latest_dll` 模式 | `implant-core/src/module/hot_reload.rs` |
| **P9d. 隔离执行** | 每模块独立 VirtualAlloc 页 + 独立线程。模块间零共享内存。卸载 = VirtualFree + 栈擦除 | `implant-core/src/module/sandbox.rs` |
| **P9e. 签名验证** | 模块二进制 ED25519 签名验证，阻止 C2 信道劫持后下发恶意模块 | `implant-core/src/module/verify.rs` |

**验收:** 两个独立模块 (`n-recon`, `n-latmove`) 同时加载 / 独立卸载 / 热更新，互不干扰。

## 第二阶段：传输韧性（P10-P11）— 补最大短板

> **2026 年前沿标准 (maldev Transport + noPROXY-c2s):** 可插拔传输层 + uTLS JA4 伪装 + CDN Domain Fronting + WebSocket 长连接 + DNS 隧道 + HTTP/2 多路复用。**同时**运行多条信道，主信道断后自动降级。

### P10. 多信道传输层（6 周）

> ⚠️ **现状对齐（AUTHORITATIVE_FACTS §0/§1）**：`transport` crate 已有 6 个 Transport impl（Malleable / DoH / Slack / LLM / MCP / SMB），**全部零消费者**——即 trait 与实现都在，但 implant/server 侧无任何消费路径。emitter 是 Err stub（见 P11a）。本阶段的核心是**接线**而非重写 trait。

| 子任务 | 细节 | 交付物 |
|--------|------|--------|
| **P10a. Transport trait** | `async fn send_frame(&mut self, frame: &[u8]) -> Result<()>` + `recv_frame()` + `channel_health()` + `latency_ms()` | `crates/transport/src/traits.rs`（**trait 已存在，6 个 impl 已存在**——缺口是消费者接线） |
| **P10b. CDN Domain Fronting** | Cloudflare Workers / Azure Front Door 中继。TLS SNI = `cdn.cloudflare.com`，HTTP Host = 真实 C2 域名。参考 Underminr (2026) 的 DNS→SNI→Host 链 | `crates/transport/src/cdn.rs` |
| **P10c. WebSocket over TLS** | 长连接 wss:// → Cloudflare → C2。在 HTTP/1.1 Upgrade 中隐藏信标流量。参考 noPROXY-c2s 的 WebSocket abuse 模式 | `crates/transport/src/ws.rs` |
| **P10d. DNS Tunneling** | TXT 记录编码 (Base64) + DoH 解析器。低速隐蔽信道（~500 bytes/query），用于心跳或降级。参考 Underminr DNSPod 劫持 | `crates/transport/src/dns.rs` |
| **P10e. HTTP/2 多路复用** | 单 TCP 连接多 Stream 并发。Stream 1 = 心跳，Stream 2 = 任务轮询，Stream 3 = 大文件传输。避免重复 TLS 握手 | `crates/transport/src/h2.rs` |
| **P10f. 信道编排器** | `TransportStack` — 主信道 HTTPS/H2 → 降级 WebSocket → 再降级 DNS。自动健康检查 + 自动切换。每信道独立 JA4 指纹 | `crates/transport/src/orchestrator.rs` |

**验收:** Wireshark 抓包 = Cloudflare CDN 流量。主信道断 → 3 秒内降到 WebSocket → 再降到 DNS TXT。零丢帧。

### P11. 流量伪装深度（4 周）

| 子任务 | 细节 | 交付物 |
|--------|------|--------|
| **P11a. uTLS 集成** | 移植 Go `refraction-networking/utls` 逻辑到 Rust。模拟 Chrome 124 / Firefox 125 / Edge 的 JA4 指纹，每次连接随机切换 | `crates/transport/src/tls_fingerprint.rs` |
| **P11b. JA4H 伪装** | HTTP Header 顺序/值模拟：`jquery-3.7.1.min.js` 下载、O365 API 调用、Windows Update 检查。参考 JA4H_a/b/c/d 四层指纹 | `crates/transport/src/http_fingerprint.rs` |
| **P11c. Malleable C2 v2** | 完全自定义：HTTP Method / URI 模板 / Header 模板 / User-Agent 池 / Cookie 模板 / POST body 模板。编译期嵌入 profile，无运行时解析 | `crates/profile/src/v2/` |
| **P11d. DGA v2** | 种子 = `HMAC(日期, 硬编码密钥)`。每日生成 256 个候选域名。注册 1-3 个，其余 sinkhole。参考 Conficker/Torpig 的域名通量 | `crates/evasion/src/dga.rs` |
| **P11e. 信标时间伪装** | 指数退避 + 30% 随机 jitter + 办公时间感知（只在 08:00-18:00 目标时区活动）+ 周末休眠 | `implant-core/src/scheduler/jitter.rs` |

**验收:** JA4 指纹库包含 50+ 现代浏览器指纹。DGA 域名 daily rotation。办公时间活动模式。
