## 阶段一：流量韧性（P8-P9）—— 补最大短板

> **优先级根因:** 流量特征是目前最大的检测面。加密再强的 beacon，单一直连 C2 就是灯塔。

### P8. 多信道传输层（4-6 周）

| 任务 | 内容 | 交付物 |
|------|------|--------|
| **P8a** | 传输层抽象 trait — `Transport` + `TransportStack` | `crates/transport/src/traits.rs` |
| **P8b** | HTTPS over CDN (Cloudflare Workers / Azure Front Door) | `transport/cdn.rs` — Host header 伪装 |
| **P8c** | DNS over HTTPS (DoH) — 低速隐蔽信道 | `transport/doh.rs` — 异步 DNS 隧道 |
| **P8d** | WebSocket over TLS — 双向长连接备用 | `transport/ws.rs` |
| **P8e** | 自动回退 — 主信道断 → CDN → DoH 降级链 | `transport/orchestrator.rs` |
| **P8f** | JA3/JA4 指纹随机化 — 每次连接不同 TLS 指纹 | `transport/fingerprint.rs` |

**验收:** `HTTPS → CDN → DoH` 三级回退自动切换，JA4 指纹每次随机，beacon 不直连 C2 IP。

### P9. 流量伪装与 DGA（3-4 周）

| 任务 | 内容 | 交付物 |
|------|------|--------|
| **P9a** | Malleable C2 profile 加强 — HTTP 方法/URI/Header/Host 全自定义 | `profile/transform.rs` 扩展 |
| **P9b** | Jitter Beacon — 指数退避 + 随机化 ±30% 睡眠 | `beacon.rs` jitter 模式 |
| **P9c** | DGA (Domain Generation Algorithm) — 时间种子域名生成 | `evasion/dga.rs` |
| **P9d** | 流量伪装 — 伪装成 Teams/Slack/O365 API 调用 | `profile/mimicry.rs` |
| **P9e** | 心跳与任务分离 — 小心跳走 DoH，大任务走 CDN | `transport/split.rs` |

**验收:** Wireshark 抓包 = O365 API 流量，无 C2 特征。域名每日变化。心跳 <100 bytes。

## 阶段二：操作安全升级（P10-P11）

> **优先级根因:** 落地写文件、不清理痕迹 = 取证分析的梦想场景。

### P10. 反取证（3-4 周）

| 任务 | 内容 | 交付物 |
|------|------|--------|
| **P10a** | Windows Timestomp — `NtSetInformationFile` 修改文件时间 | `anti_forensics/timestomp.rs` |
| **P10b** | USN Journal 清理 — `FSCTL_DELETE_USN_JOURNAL` + 选择性记录抹除 | `anti_forensics/usn.rs` |
| **P10c** | Prefetch 清理 — `C:\Windows\Prefetch\*.pf` 删除 | `anti_forensics/prefetch.rs` |
| **P10d** | Event Log 清理 — 安全/系统/应用日志选择性擦除 | `anti_forensics/eventlog.rs` |
| **P10e** | Memory-only mode — 零磁盘落地路径（纯注入 + 内存驻留） | `entry.rs` 内存模式 |

**验收:** `Velociraptor / KAPE` 取证采集看不到植入痕迹。时间线一致，无异常。

### P11. 持久化多路径（2-3 周）

| 任务 | 内容 | 交付物 |
|------|------|--------|
| **P11a** | WMI 事件订阅 — `__EventFilter` + `__FilterToConsumerBinding` | `persistence/wmi.rs` |
| **P11b** | COM 劫持 — `TreatAs` / `InprocServer32` 重定向 | `persistence/com_hijack.rs` |
| **P11c** | 计划任务 — `ITaskService` XML 任务（无 `schtasks.exe`） | `persistence/schtask_com.rs` |
| **P11d** | DLL 侧加载 — 利用合法签名 EXE 的 DLL 搜索顺序 | `persistence/sideload.rs` |
| **P11e** | 自愈看门狗 — 主进程被杀 → 备用路径自动重启 | `persistence/watchdog.rs` |

**验收:** 三路径同时部署。杀一重生。Autoruns 不可见（WMI + COM）。
